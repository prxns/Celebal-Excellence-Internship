## Final Major Project — Apex Retail Intelligence

The internship culminated in **Apex Retail Intelligence**, an end-to-end retail data engineering pipeline developed with **Databricks and PySpark**.

### Architecture

```text
Raw → Landing → Bronze → Silver → Gold → KPI Reporting
```

The project brings together the concepts developed throughout the internship, including:

- Historical and incremental data ingestion
- Data quality and reconciliation checks
- Bronze and Silver Delta processing
- Customer SCD Type 2 processing
- Gold Star Schema modelling
- Referential-integrity validation
- Business KPI reporting directly in Databricks

### Mandatory KPIs

1. **Net Margin by Region**
2. **Average Order Value by Promotion**
3. **Demographic Churn Heatmap**
4. **Product Quality Index**
5. **Store Traffic Proxy**
