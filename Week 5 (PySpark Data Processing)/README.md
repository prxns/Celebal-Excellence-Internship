# Celebal Spark DataFrame Assessment

## Project Overview

This repository contains my Apache Spark (PySpark) assessment completed
as part of the Celebal Technologies program. It demonstrates fundamental
DataFrame operations, data cleaning, transformations, filtering,
aggregation, and schema manipulation.

## Topics Covered

-   Spark vs. MapReduce
-   In-Memory Computing
-   DataFrame Immutability
-   Removing Duplicates
-   Handling Null Values
-   Filtering Data
-   Grouping and Aggregation
-   Shuffle and Wide Transformations
-   Timestamp Conversion
-   End-to-End Data Processing Pipeline
